# 🧱 BrickForge AI
**Local Roblox Creature Foundry**

A fully local, offline AI that designs blocky/sharp Roblox-style character models with a Motor6D rigging system. It understands text prompts, reference images, and learns from your feedback to build better creatures over time.

## ✨ Features
- **🧠 Cognitive Core:** Real intent parsing (negations, counts, materials, moods) + color theory synthesis.
- **🏗️ Procedural Anatomy:** Uses curve math (Catmull-Rom, Phyllotaxis, Log Spirals) for organic blocky shapes.
- **️ Self-Critique:** The AI builds 6–12 candidates internally, scores them against your prompt, and delivers only the best one.
- **🦴 Rigging System:** Exports ready-to-use Roblox Lua scripts with `Motor6D` hierarchies + `Humanoid`.
- ** Interactive UI:** Light-mode comfort design, 3D viewport, turntable, palette remixing, and memory gallery.
- **🔒 100% Local:** No API keys, no cloud. Runs entirely on your machine.
